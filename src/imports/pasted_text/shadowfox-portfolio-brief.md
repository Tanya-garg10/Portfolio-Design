# 2. Design Direction

### Style

**Modern • Minimal • Creative • Tech-focused**

### Suggested palette

Use:

**Inter**

* H1 → 64 px / Bold
* H2 → 40 px / Bold
* H3 → 24 px / SemiBold
* Body → 18 px / Regular
* Small text → 14 px

# 8. SCREEN 05 — Design Process

Beginner task mein ye section tumhari **UX thinking** demonstrate karega.

**How I Design**

### 01 — Discover

> Understand the problem, users and requirements.

### 02 — Define

> Organize insights and identify the core user needs.
